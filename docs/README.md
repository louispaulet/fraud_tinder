# Fraud Tinder Documentation

This folder contains project documentation for contributors and agents.

It is intentionally kept outside `src/` and `public/`, so it is not bundled by Vite and is not deployed to GitHub Pages. The deployment command publishes only the generated `dist/` directory.

## Documents

- `project_overview.md`: Product concept, gameplay loop, UX principles, and implementation shape.
- `content_guidelines.md`: Rules for creating fictional scam and not-scam cases safely.
- `tone_of_voice.md`: Copywriting guidance for wording used on the website.

## Maintenance

Update these docs whenever the product direction, gameplay, content rules, tone, commands, or deployment model changes.
